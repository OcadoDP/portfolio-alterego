Note on Project Scope: "Project EmpowerPH" is a simulated capstone project developed entirely for portfolio demonstration. All data points are dynamically generated using a custom Python script to test scale and visualization limits.

The Challenge

To demonstrate my ability to architect full-data pipelines, I designed a theoretical scenario: evaluating a nationwide digital literacy rollout across 17 Philippine regions. The hypothetical constraints required a secure, offline-capable dashboard that could instantly process and display thousands of survey rows without relying on an external database backend.

The Solution

I built an end-to-end data pipeline combining Python scripting with modern frontend web technologies:

  • Synthetic Data Engineering (Python & Pandas): I developed a Python script utilizing pandas to programmatically generate scalable batches of mock survey data. The script intelligently weighted regional population distributions, employment sectors, and device usage to mirror actual demographics, injecting realistic qualitative feedback based on each course track.
  • Client-Side Processing (Fetch API & SheetJS): I engineered the frontend using TailwindCSS and Chart.js. Rather than hardcoding the data or requiring a server, the application uses the JavaScript Fetch API to pull the generated .xlsx file directly from GitHub Pages, parses it locally via `SheetJS`, and populates the charts and metrics instantly.
  • Power BI Integration: To complete the portfolio narrative, I developed a parallel executive dashboard in Power BI using the exact same dataset to demonstrate multi-platform data storytelling.

The Impact

This mock project serves as a comprehensive showcase of my data engineering capabilities. The resulting dashboard is a highly responsive, zero-backend reporting tool. The integrated Likert matrices, trend lines, and region filters allow for immediate visual analysis, proving my ability to turn raw tabular inputs into interactive, professional-grade analytics.
